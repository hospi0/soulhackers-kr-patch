## 글꼴·글자 코드 (2026-11-24 확정)
- **A_FONT16.BIN = 16×16 1bpp 2,048칸**(칸당 32 B), WorkRAML 0x00200000 에 통째로 적재. 칸 0~ 기호·작은 가나, ASCII 칸 = ASCII+0x120, 0x1A1~ 히라가나, 0x200~ 가타카나, 그 뒤 한자 ~1,500. 그림 `work/survey/font16_1bpp.png`
- **글 코드 = 2바이트 `110xxxxx 10xxxxxx`(UTF-8 꼴) → 11비트 값 = 글꼴 칸 그대로**. 0xFF xx = 제어(줄바꿈 등). 상한 0x7FF = 2,047 → 한글 음절 수 예산이 관건(초벌 뒤 판정)
  - 확인: 대사(2) 스테이트 WorkRAML 0x41000 대본 → 「【ヒトミ】……ねぇ、ここなら大丈夫じゃない？」 그대로 읽힘, 같은 바이트가 EVENT.BIN 0x3a71c(압축 없음)
- 화면 그리기: VDP2 VRAM 8bpp 셀에 CPU 가 글자를 그림(대사(2) 0x6cbc0~ こ·こ·な)
- 앞서 쓴 「−0x60」 식은 틀림(우연), 지움.
